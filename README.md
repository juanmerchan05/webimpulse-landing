# WebImpulse

Landing page profesional para un servicio de desarrollo web dirigido a pequeños emprendimientos, artesanos y negocios locales.

## Objetivo
WebImpulse ayuda a pequeños negocios a presentar sus productos y servicios mediante una presencia digital clara, accesible y adaptable a dispositivos móviles. Este repositorio reúne la landing comercial, una herramienta complementaria de apoyo creativo y las evidencias de la Unidad 3.

## Sitio publicado
- Landing principal: https://juanmerchan05.github.io/webimpulse-landing/
- Herramienta Studio: https://juanmerchan05.github.io/webimpulse-landing/studio/

## Estructura
- `index.html`, `styles.css`, `script.js`: landing comercial estática.
- `assets/images/`: imágenes de la landing.
- `landing.html`: copia de referencia del HTML original.
- `studio/`: aplicación complementaria React, TypeScript y Vite.
- `docs/auditoria/`, `docs/persistencia/`, `docs/snippets/`, `docs/evidencias/`: informes y evidencias de Unidad 3.
- `.github/workflows/`: automatización de GitHub Pages.

## Tecnologías
HTML5 semántico, CSS y JavaScript para la landing; React, TypeScript y Vite para Studio; GitHub Actions para publicación.

## Desarrollo local
Landing: abre `index.html` mediante un servidor local.

Studio:
```bash
cd studio
npm install
npm run dev
```

Construcción de Studio:
```bash
npm run build
```

## Actividades Unidad 3
Durante la Unidad 3 se realizaron actividades de auditoría crítica del código generado con IA, implementación y verificación de persistencia mediante `localStorage`, integración del envío del formulario con Formspree y documentación de componentes reutilizables.

También se verificó el funcionamiento de la landing publicada, se organizaron las tareas mediante Issues y un tablero de GitHub Projects, y se registraron evidencias del proceso.

La documentación y los materiales de soporte se encuentran organizados en `docs/`.
