# Evidencias de la Unidad 3

Esta carpeta reúne las capturas que permiten comprobar el desarrollo, las pruebas y la publicación de WebImpulse.

Guarda las imágenes en esta carpeta y utiliza nombres descriptivos:

## Cómo agregar las capturas

1. Toma o selecciona las capturas reales de cada comprobación.
2. Si es necesario, oculta correos, nombres, tokens u otra información personal.
3. Sube las imágenes a esta carpeta manteniendo los nombres sugeridos o usando nombres equivalentes y descriptivos.
4. Comprueba que cada imagen se pueda abrir desde GitHub.

## Criterio de evidencia

Las capturas deben corresponder a resultados observados en el proyecto. Esta guía no sustituye las imágenes: cada evidencia visual debe añadirse como archivo real. No se deben presentar capturas ilustrativas o recreadas como si fueran pruebas de funcionamiento.
