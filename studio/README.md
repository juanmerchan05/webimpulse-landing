# WebImpulse Studio

Aplicación complementaria de apoyo creativo desarrollada con React, TypeScript y Vite.

## Requisitos
Node.js LTS y npm.

## Instalar y ejecutar
```bash
npm install
npm run dev
```

## Construir
```bash
npm run build
```

La landing comercial principal está en la raíz. Studio se publica bajo `/studio/`.
